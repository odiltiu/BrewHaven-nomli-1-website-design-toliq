# BrewHaven — kofe do'koni sayti

Kofe do'koni uchun bir sahifali landing sayt dizayni (HTML, CSS, JavaScript).

- Header, hero, mahsulotlar (Signature Blends) va footer bo'limlari
- Telefon va planshetga moslashgan
- Shriftlar: Montserrat (matn) va Playfair Display (sarlavhalar), ikonkalar: Font Awesome

Ishga tushirish: `index.html` ni brauzerda oching.
